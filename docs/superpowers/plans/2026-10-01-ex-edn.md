# ex_edn Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A dependency-free EDN reader and writer for Elixir, in namespace `EDN`, that replaces Eden in `wagger`, `llmagent` and `yesman_instance` by mechanical rename.

**Architecture:** One hand-written recursive-descent decoder over the binary (positions computed from byte offsets only when an error is raised), a protocol-based encoder, and small structs for the EDN types Elixir lacks. Vectors wrap OTP `:array`; `#inst` uses stdlib `DateTime`.

**Tech Stack:** Elixir (developed on 1.19.5 / OTP 28), ExUnit. No runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-10-01-ex-edn-design.md` (EDN grammar: `edn/edn.md`)

## Global Constraints

- Zero runtime dependencies (`deps: []`); `:array`, `DateTime` and `:calendar` only.
- Namespace `EDN`, package and app `ex_edn`. The `Eden` name is not used and there is no `Eden` shim.
- License AGPLv3 (`licenses: ["AGPL-3.0-only"]`).
- API: `EDN.decode/2`, `decode!/2`, `encode/1`, `encode!/1`. Errors are `{:error, %EDN.Error.*{}}` carrying `:line` and `:col`.
- Decode options: `:handlers`, `:keywords` (`:atom` default, `:safe`), `:vectors` (`:vector` default, `:list`), `:max_depth` (default 512).
- One top-level form decodes to its value, several to a list, none raises `EDN.Error.EmptyInput`.
- Mapping is Eden's with renames: vector is `%EDN.Vector{}`, list is a list, keyword is an atom, `#inst` is a UTC `%DateTime{}`.
- Written fresh: do not copy code from `~/github/Eden` (Apache-2.0).
- Elixir floor `~> 1.15` is a chosen default; only 1.19.5 is tested.
- Every code block below was run before it was written here. Run `mix format` after pasting; the files are already formatted.

## Review Focus

Inputs the spec implies but its examples never exercise, most likely first. Each has a pinning test in the task that owns the code.

1. File starts with a UTF-8 byte order mark: ignored, not a parse error (Task 2).
2. CRLF line endings, including after `;` comments, with correct line numbers (Task 2).
3. A stray closer after a complete form, `{:a 1}}`: `UnbalancedDelimiter` at the right column (Task 3).
4. Encoding a binary that is not valid UTF-8: an error, never invalid EDN (Task 4).
5. Charlists (`~c"ab"`) encode as lists of integers, not strings (Task 4); this pins existing Eden behavior.

```elixir
defmodule EDN.Error do
  @moduledoc """
  Exceptions raised by `EDN.decode!/2` and `EDN.encode!/1`.

  Every exception carries `:message`, and `:line` and `:col` (1-based) when
  the problem has a position in the input.
  """

  @names [
    UnexpectedInput,
    UnfinishedToken,
    UnbalancedDelimiter,
    OddExpressionCount,
    IncompleteTag,
    MissingDiscardExpression,
    EmptyInput,
    InvalidTagValue
  ]

  for name <- @names do
    defmodule Module.concat(__MODULE__, name) do
      defexception [:message, :line, :col]
    end
  end

  @doc false
  def all, do: unquote(for name <- @names, do: Module.concat(__MODULE__, name))
end
```

```elixir
defmodule EDN.Symbol do
  @moduledoc "An EDN symbol, e.g. `my.ns/foo`."
  defstruct [:name]
  def new(name) when is_binary(name), do: %__MODULE__{name: name}
end

defmodule EDN.Character do
  @moduledoc "An EDN character, e.g. `\\a` or `\\newline`. `:char` is a one-character binary."
  defstruct [:char]
  def new(char) when is_binary(char), do: %__MODULE__{char: char}
end

defmodule EDN.UUID do
  @moduledoc "An EDN `#uuid` value. `:value` is the canonical string form."
  defstruct [:value]
  def new(value) when is_binary(value), do: %__MODULE__{value: value}
end

defmodule EDN.Tag do
  @moduledoc """
  A tagged element with no registered handler, e.g. `#myapp/Person {...}`.
  Also holds the default `#inst` and `#uuid` handlers.
  """
  alias EDN.Error.InvalidTagValue

  defstruct [:name, :value]
  def new(name, value) when is_binary(name), do: %__MODULE__{name: name, value: value}

  @doc "Default `#inst` handler: RFC 3339 string to a UTC `DateTime`."
  def inst(value) when is_binary(value) do
    case DateTime.from_iso8601(value) do
      {:ok, datetime, _offset} -> datetime
      {:error, _} -> invalid("#inst", value)
    end
  end

  def inst(value), do: invalid("#inst", value)

  @doc "Default `#uuid` handler: canonical UUID string to `%EDN.UUID{}`."
  def uuid(value) when is_binary(value) do
    if Regex.match?(
         ~r/\A[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}\z/,
         value
       ),
       do: %EDN.UUID{value: value},
       else: invalid("#uuid", value)
  end

  def uuid(value), do: invalid("#uuid", value)

  defp invalid(tag, value),
    do: raise(InvalidTagValue, message: "invalid #{tag} value: #{inspect(value)}")
end
```

```elixir
defmodule EDN.Vector do
  @moduledoc """
  An EDN vector: indexed, with O(log n) access, backed by OTP `:array`.

  Built only through `from_list/1`, so equal contents compare `==`.
  """
  defstruct array: :array.new()

  @opaque t :: %__MODULE__{}

  @spec from_list(list) :: t
  def from_list(list) when is_list(list), do: %__MODULE__{array: :array.from_list(list)}

  @spec to_list(t) :: list
  def to_list(%__MODULE__{array: array}), do: :array.to_list(array)

  @spec size(t) :: non_neg_integer
  def size(%__MODULE__{array: array}), do: :array.size(array)

  @doc "Element at zero-based `index`, or `default` when out of range."
  @spec get(t, integer, term) :: term
  def get(%__MODULE__{array: array}, index, default \\ nil) when is_integer(index) do
    if index >= 0 and index < :array.size(array), do: :array.get(index, array), else: default
  end

  defimpl Enumerable do
    def count(v), do: {:ok, EDN.Vector.size(v)}
    def member?(_v, _x), do: {:error, __MODULE__}
    def slice(_v), do: {:error, __MODULE__}
    def reduce(v, acc, fun), do: Enumerable.List.reduce(EDN.Vector.to_list(v), acc, fun)
  end

  defimpl Inspect do
    import Inspect.Algebra

    def inspect(v, opts),
      do: concat(["#EDN.Vector<", to_doc(EDN.Vector.to_list(v), opts), ">"])
  end
end
```

`lib/edn/decoder.ex`:

```elixir
defmodule EDN.Decoder do
  @moduledoc false
  # One recursive-descent pass over the binary. `rest` is always a suffix of
  # `ctx.input`, so error positions are computed from byte offsets on failure
  # only; there is no per-character line/column bookkeeping.

  alias EDN.{Character, Symbol}
  alias EDN.Error

  @ws [?\s, ?\t, ?\n, ?\r, ?,]
  @closers [?), ?], ?}]
  @delims @ws ++ [?{, ?}, ?(, ?), ?[, ?], ?", ?;]

  @doc "Decodes every top-level form in `input` into a list."
  def forms(input, opts) do
    unless String.valid?(input),
      do: raise(Error.UnexpectedInput, message: "input is not valid UTF-8")

    # Files saved by some editors start with a UTF-8 byte order mark.
    input = String.replace_prefix(input, "\uFEFF", "")

    ctx = %{
      input: input,
      handlers: Keyword.fetch!(opts, :handlers),
      keywords: Keyword.fetch!(opts, :keywords),
      vectors: Keyword.fetch!(opts, :vectors),
      max_depth: Keyword.fetch!(opts, :max_depth),
      discard: false
    }

    forms(input, ctx, [])
  end

  defp forms(rest, ctx, acc) do
    case skip(rest, ctx, 0) do
      "" ->
        Enum.reverse(acc)

      rest ->
        {value, rest} = value(rest, ctx, 0)
        forms(rest, ctx, [value | acc])
    end
  end

  # -- whitespace and comments ------------------------------------------------

  defp skip(<<c, rest::binary>>, ctx, depth) when c in @ws, do: skip(rest, ctx, depth)

  defp skip(<<?;, rest::binary>>, ctx, depth) do
    case :binary.split(rest, "\n") do
      [_comment_to_eof] -> ""
      [_comment, rest] -> skip(rest, ctx, depth)
    end
  end

  defp skip(rest, _ctx, _depth), do: rest

  # -- values -------------------------------------------------------------------

  defp value(<<c, _::binary>> = at, ctx, _depth) when c in @closers,
    do: fail(Error.UnbalancedDelimiter, ctx, at, "unexpected #{<<c>>}")

  defp value(<<?", rest::binary>> = at, ctx, _depth), do: string(rest, at, ctx, [])

  defp value(<<?\\, rest::binary>> = at, ctx, _depth) do
    case rest do
      <<c::utf8, tail::binary>> when c not in @ws ->
        {more, tail} = token(tail)
        {%Character{char: char_name(<<c::utf8>> <> more, ctx, at)}, tail}

      _ ->
        fail(Error.UnexpectedInput, ctx, at, "backslash must be followed by a character")
    end
  end

  defp value(rest, ctx, _depth) do
    case token(rest) do
      {"", _} -> fail(Error.UnexpectedInput, ctx, rest, "unexpected input")
      {token, tail} -> {atom(token, ctx, rest), tail}
    end
  end

  # -- strings and characters -----------------------------------------------------

  defp string(rest, at, ctx, acc) do
    case :binary.match(rest, [~s("), "\\"]) do
      :nomatch ->
        fail(Error.UnfinishedToken, ctx, at, "unterminated string")

      {i, 1} ->
        <<chunk::binary-size(i), c, tail::binary>> = rest
        acc = [acc, chunk]

        case {c, tail} do
          {?", _} ->
            {IO.iodata_to_binary(acc), tail}

          {?\\, <<?u, hex::binary-size(4), tail::binary>>} ->
            case unicode(hex) do
              {:ok, char} -> string(tail, at, ctx, [acc, char])
              :error -> fail(Error.UnexpectedInput, ctx, tail, "invalid \\u escape")
            end

          {?\\, <<?t, tail::binary>>} ->
            string(tail, at, ctx, [acc, "\t"])

          {?\\, <<?r, tail::binary>>} ->
            string(tail, at, ctx, [acc, "\r"])

          {?\\, <<?n, tail::binary>>} ->
            string(tail, at, ctx, [acc, "\n"])

          {?\\, <<?\\, tail::binary>>} ->
            string(tail, at, ctx, [acc, "\\"])

          {?\\, <<?", tail::binary>>} ->
            string(tail, at, ctx, [acc, ~s(")])

          {?\\, ""} ->
            fail(Error.UnfinishedToken, ctx, at, "unterminated string")

          {?\\, tail} ->
            fail(Error.UnexpectedInput, ctx, tail, "invalid escape in string")
        end
    end
  end

  defp char_name("newline", _, _), do: "\n"
  defp char_name("return", _, _), do: "\r"
  defp char_name("space", _, _), do: " "
  defp char_name("tab", _, _), do: "\t"

  defp char_name(<<?u, hex::binary-size(4)>> = token, ctx, at) do
    case unicode(hex) do
      {:ok, char} -> char
      :error -> char_name_fallback(token, ctx, at)
    end
  end

  defp char_name(token, ctx, at), do: char_name_fallback(token, ctx, at)

  defp char_name_fallback(token, ctx, at) do
    if String.length(token) == 1,
      do: token,
      else: fail(Error.UnexpectedInput, ctx, at, "unknown character \\#{token}")
  end

  # `\uNNNN` as in Java. Surrogate halves are not scalar values: rejected.
  defp unicode(hex) do
    with true <- Regex.match?(~r/\A[0-9a-fA-F]{4}\z/, hex),
         {cp, ""} <- Integer.parse(hex, 16),
         true <- cp not in 0xD800..0xDFFF do
      {:ok, <<cp::utf8>>}
    else
      _ -> :error
    end
  end

  # -- atoms: nil, booleans, numbers, keywords, symbols ---------------------------

  defp atom("nil", _, _), do: nil
  defp atom("true", _, _), do: true
  defp atom("false", _, _), do: false
  defp atom(":" <> name, ctx, at), do: keyword(name, ctx, at)
  defp atom(<<c, _::binary>> = token, ctx, at) when c in ?0..?9, do: number(token, ctx, at)

  defp atom(<<s, d, _::binary>> = token, ctx, at) when s in [?+, ?-] and d in ?0..?9,
    do: number(token, ctx, at)

  defp atom(token, ctx, at) do
    if symbol_name?(token),
      do: %Symbol{name: token},
      else: fail(Error.UnexpectedInput, ctx, at, "invalid symbol #{inspect(token)}")
  end

  defp keyword(name, ctx, at) do
    unless name != "/" and symbol_name?(name),
      do: fail(Error.UnexpectedInput, ctx, at, "invalid keyword :#{name}")

    case ctx.keywords do
      :atom ->
        String.to_atom(name)

      :safe ->
        try do
          String.to_existing_atom(name)
        rescue
          ArgumentError ->
            fail(Error.UnexpectedInput, ctx, at, "keyword :#{name} is not an existing atom")
        end
    end
  end

  defp number(token, ctx, at) do
    cond do
      Regex.match?(~r/\A[+-]?(?:0|[1-9][0-9]*)N?\z/, token) ->
        token |> String.trim_trailing("N") |> String.to_integer()

      Regex.match?(~r/\A[+-]?(?:0|[1-9][0-9]*)(?:\.[0-9]+)?(?:[eE][+-]?[0-9]+)?M?\z/, token) ->
        case token |> String.trim_trailing("M") |> Float.parse() do
          {float, ""} -> float
          _ -> fail(Error.UnexpectedInput, ctx, at, "number out of range: #{token}")
        end

      true ->
        fail(Error.UnexpectedInput, ctx, at, "invalid number #{inspect(token)}")
    end
  end

  # Symbol grammar from the spec: first char non-numeric; a leading - + . must
  # not be followed by a digit; `/` once, with non-empty prefix and name, or
  # alone.
  defp symbol_name?("/"), do: true

  defp symbol_name?(token) do
    case String.split(token, "/") do
      [name] -> symbol_part?(name)
      [prefix, name] -> symbol_part?(prefix) and symbol_part?(name)
      _ -> false
    end
  end

  defp symbol_part?(part),
    do:
      Regex.match?(
        ~r/\A(?:[\p{L}*!_?$%&=<>]|[-+.](?![0-9]))[\p{L}\p{N}.*+!\-_?$%&=<>:#]*\z/u,
        part
      )

  # -- helpers ------------------------------------------------------------------------

  # Splits off bytes up to the next whitespace or delimiter.
  defp token(bin), do: token(bin, 0)

  defp token(bin, n) do
    case bin do
      <<_::binary-size(n), c, _::binary>> when c not in @delims -> token(bin, n + 1)
      _ -> {binary_part(bin, 0, n), binary_part(bin, n, byte_size(bin) - n)}
    end
  end

  defp fail(module, ctx, rest, message) do
    {line, col} = position(ctx.input, rest)

    raise module,
      message: "#{message} at line #{line}, column #{col}",
      line: line,
      col: col
  end

  defp position(input, rest) do
    consumed = binary_part(input, 0, byte_size(input) - byte_size(rest))
    lines = String.split(consumed, "\n")
    {length(lines), String.length(List.last(lines)) + 1}
  end
end
```

```elixir
defmodule EDN do
  @moduledoc """
  EDN (extensible data notation) reader and writer. See `decode/2` and
  `encode/1`. No runtime dependencies.
  """

  alias EDN.Error

  @default_handlers %{"inst" => &EDN.Tag.inst/1, "uuid" => &EDN.Tag.uuid/1}

  @doc """
  Decodes EDN text. One top-level form returns its value; several return a
  list of values.

  ## Options

    * `:handlers` - `%{"my/tag" => fun}`; `fun` receives the decoded tagged
      element. Merged over the default `inst` and `uuid` handlers.
    * `:keywords` - `:atom` (default, `String.to_atom/1`) or `:safe`
      (`String.to_existing_atom/1`). Use `:safe` on untrusted input: atoms are
      never garbage collected.
    * `:vectors` - `:vector` (default, `%EDN.Vector{}`) or `:list`.
    * `:max_depth` - maximum nesting depth, default 512.
  """
  @spec decode(String.t(), keyword) :: {:ok, term} | {:error, Exception.t()}
  def decode(input, opts \\ []) do
    {:ok, decode!(input, opts)}
  rescue
    e -> to_error(e, __STACKTRACE__)
  end

  @doc "Like `decode/2`, but returns the value and raises `EDN.Error.*` on failure."
  @spec decode!(String.t(), keyword) :: term
  def decode!(input, opts \\ []) when is_binary(input) do
    opts = [
      handlers: Map.merge(@default_handlers, Keyword.get(opts, :handlers, %{})),
      keywords: Keyword.get(opts, :keywords, :atom),
      vectors: Keyword.get(opts, :vectors, :vector),
      max_depth: Keyword.get(opts, :max_depth, 512)
    ]

    case EDN.Decoder.forms(input, opts) do
      [] -> raise Error.EmptyInput, message: "no EDN forms in input"
      [form] -> form
      forms -> forms
    end
  end

  defp to_error(%{__struct__: module} = e, stacktrace) do
    if module in Error.all(), do: {:error, e}, else: reraise(e, stacktrace)
  end
end
```

```elixir
defprotocol EDN.Encode do
  @moduledoc """
  Turns a term into EDN text. Implement it for your own structs to control
  their representation; structs without an implementation encode as maps.
  """
  @fallback_to_any true

  @spec encode(t) :: String.t()
  def encode(term)
end

defmodule EDN.Encode.Util do
  @moduledoc false

  def join(items, open, close),
    do: open <> Enum.map_join(items, ", ", &EDN.Encode.encode/1) <> close

  def escape(string) do
    for <<c <- string>>, into: "" do
      case c do
        ?" -> ~S(\")
        ?\\ -> ~S(\\)
        ?\n -> ~S(\n)
        ?\r -> ~S(\r)
        ?\t -> ~S(\t)
        c -> <<c>>
      end
    end
  end

  # Mirrors the decoder's symbol grammar so we never emit text we cannot read back.
  def name!(name) do
    if name == "/" or
         (Enum.all?(String.split(name, "/"), &part?/1) and length(String.split(name, "/")) <= 2),
       do: name,
       else: raise(ArgumentError, "not a valid EDN name: #{inspect(name)}")
  end

  defp part?(part),
    do:
      Regex.match?(
        ~r/\A(?:[\p{L}*!_?$%&=<>]|[-+.](?![0-9]))[\p{L}\p{N}.*+!\-_?$%&=<>:#]*\z/u,
        part
      )
end

defimpl EDN.Encode, for: Atom do
  def encode(atom) when atom in [nil, true, false], do: Atom.to_string(atom)
  def encode(atom), do: ":" <> EDN.Encode.Util.name!(Atom.to_string(atom))
end

defimpl EDN.Encode, for: BitString do
  def encode(string) when is_binary(string) do
    if String.valid?(string),
      do: ~s(") <> EDN.Encode.Util.escape(string) <> ~s("),
      else: raise(ArgumentError, "binary is not valid UTF-8: #{inspect(string)}")
  end

  def encode(bits),
    do: raise(Protocol.UndefinedError, protocol: EDN.Encode, value: bits)
end

defimpl EDN.Encode, for: Integer do
  def encode(int), do: Integer.to_string(int)
end

defimpl EDN.Encode, for: Float do
  def encode(float), do: Float.to_string(float)
end

defimpl EDN.Encode, for: List do
  def encode(list), do: EDN.Encode.Util.join(list, "(", ")")
end

defimpl EDN.Encode, for: Map do
  def encode(map) do
    "{" <>
      Enum.map_join(map, ", ", fn {k, v} ->
        EDN.Encode.encode(k) <> " " <> EDN.Encode.encode(v)
      end) <> "}"
  end
end

  def encode(set), do: EDN.Encode.Util.join(set, "\#{", "}")
```

````markdown
# ex_edn

EDN (extensible data notation) reader and writer for Elixir. No dependencies.

```elixir
iex> EDN.decode("{:a 1, :b [1 2 3]}")
{:ok, %{a: 1, b: #EDN.Vector<[1, 2, 3]>}}

iex> EDN.encode(%{a: 1})
{:ok, "{:a 1}"}
```

## Type mapping

| EDN | Elixir |
| --- | --- |
| `nil`, `true`, `false` | `nil`, `true`, `false` |
| string | binary |
| integer, float (`N`, `M` suffixes accepted) | integer, float |
| keyword | atom |
| list | list |
| vector | `%EDN.Vector{}` |
| map | map |
| set | `MapSet` |
| symbol | `%EDN.Symbol{}` |
| character | `%EDN.Character{}` |
| `#inst` | `%DateTime{}` (UTC) |
| `#uuid` | `%EDN.UUID{}` |
| unknown tag | `%EDN.Tag{}` |

Decoding one top-level form returns its value; several forms return a list.

## Options

- `handlers:` a map of tag name to function, merged over the `inst` and `uuid` defaults.
- `keywords: :safe` uses `String.to_existing_atom/1`. The default, `String.to_atom/1`, lets untrusted input grow the atom table; use `:safe` for anything you do not control.
- `vectors: :list` decodes vectors to plain lists.
- `max_depth:` nesting limit, default 512.

## Errors

`decode/2` and `encode/1` return `{:error, exception}`. Decode errors are `EDN.Error.*` structs carrying `:line` and `:col`.

## Notes

- Encoding writes elements separated by `", "`. Map entry order is unspecified, as in EDN itself.
- Charlists encode as lists of integers. Tuples, pids and other non-EDN terms return an error.
- Binaries that are not valid UTF-8 are rejected on encode.

## Migrating from Eden

Rename `Eden` to `EDN`, `Array.from_list/to_list` to `EDN.Vector.from_list/to_list`, and `Eden.Symbol` and friends to `EDN.Symbol` and friends. Errors are now `{:error, %EDN.Error.X{}}` instead of `{:error, Eden.Exception.X}`.

AGPL-3.0-only.
````
